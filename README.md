This is my version of the ISBN 13 "check digit" problem, written in Python. 
On Linux, for it to have proper permissions for it to run with the command "./check_digit.py" command, you will need to do "chmod +x check_digit.py".
The other way to run it is using "python3 check_digit.py". 
On Windows and MacOS, it is recommended to use an IDE of your choice.
